# 发消息 / 发邮件工作流

适用于：通过 QQ 邮箱发信（`qq_mail_send`），以及需要用户确认的任何写操作。

## 步骤（QQ 邮箱发信）

1. **确认身份可用**：`qq_mail_list_recent` 成功返回即代表邮箱连接正常；若 `409`，先引导用户连接 QQ 邮箱。
2. **起草内容**：根据用户需求写主题与正文；`to` 取用户提供的收件人。
3. **⛔ 确认**：把「收件人 + 主题 + 正文概要（2 句内）」复述给用户，等明确同意。
   - 用户要求「直接发」也算确认；用户没给收件人时必须先问。
4. **发送**：`qq_mail_send({ to, subject, text })`。
5. **回报**：`已发送 → 收件人 / 主题`；失败时给错误原文并建议下一步。

## 其他写操作

- 涉及删除、批量发送、公开可见的改动：一律先确认，再执行。
- 浏览器代操作（`connected_app_open`）会打开本机窗口：先告知用户「将打开浏览器窗口」，再调用。

## 检查点

- [ ] 收件人与主题已确认
- [ ] 发送结果真实来自工具返回，不编造
- [ ] 失败时包含可行动的下一步（如「去连接中心检查授权码」）
