# 长对话压缩

自动压缩默认使用按需语义摘要：只有机械摘要会被截短，或需要继续整理已有语义摘要时，才向当前绑定的模型请求摘要。短对话不会额外调用模型。它是通用的文本 map/reduce 流程，不要求提供商支持 OpenAI `/compact`，也不等价于提供商的原生压缩接口。

## 配置与预算

| 环境变量 | 默认值 | 作用 |
|---|---|---|
| `GUGO_CONTEXT_SEMANTIC_SUMMARY` | `auto` | `off` 关闭；`auto` 按需；`always` 每次需要压缩时尝试语义摘要 |
| `GUGO_CONTEXT_SEMANTIC_MAX_CALLS` | `12` | 单次压缩的模型调用上限，最高 32 |
| `GUGO_CONTEXT_SEMANTIC_TIMEOUT_MS` | `45000` | 单次压缩的总时间预算，最高 120000 毫秒 |

宿主也可向 `runToolLoop` 传入 `semanticSummary: false`，或 `{ mode: 'auto', maxCalls: 8, timeoutMs: 30000 }`。摘要请求使用当前绑定的提供商和模型，因此可能产生额外的上游模型费用；计入任务已有的模型调用、token 预算与请求记录。摘要的输入和输出另有 token 上限，输出上限会实际传入原生/兼容请求体。

## 保真与安全边界

超长消息按顺序完整分片，覆盖中部文本和工具参数，不在摘要模型看到内容之前做头尾截断。摘要输出不能带工具调用；无效、截断或超限输出不能伪装成有效语义摘要。规划所需调用数先与上限比较，无法完整处理时不会只总结开头就宣称成功。

摘要是非权威的续跑参考，不是完整可靠的记忆。当前任务的原始请求、授权、工具范围、审批与执行检查点仍独立生效。摘要不能扩大只读任务的权限。历史原文保留在 canonical history 或受用户隔离保护的压缩档案；存在档案时，摘要包含 `/api/compaction/archive/<id>` 的精确取回引用。

摘要与主回答拥有独立的模型请求槽。阶段结果与已准备的上下文采用有界检查点，恢复时复用已完成的摘要/回答及原档案，不重新计费发送。摘要不会消耗当前用户消息的首次附件展开机会，也不会把摘要正文作为用户可见答案流出。

旧版本检查点可能没有已准备的压缩上下文。此时先在本地重建机械视图，再核对原主请求的指纹；核对前不会调用摘要模型或创建新档案。能够证明请求一致时，复用已完成回答或处理已核实的未发送结果；无法重建时停止恢复并保留原请求槽。未知主请求未核清前，不会另发摘要请求。

## 降级与取消

普通摘要失败、无效输出或预算不足会退回机械摘要，并显示降级状态；机械摘要可能遗漏细节，不能据此声称完整记忆。原始记录不会被该降级覆盖。

用户取消会停止压缩。超时会中止摘要请求，并隔离不响应取消的适配器；晚到结果不得继续写检查点。若已发送请求的上游结果仍未知，真实工具循环不会继续发送主请求，而是保留摘要请求槽等待人工核对。已知失败才可以自动降级续跑。
