# 调度语义

Gugo 的 cron、interval 与 heartbeat 统一采用以下规则：

- `run-once catch-up`：服务恢复时，已经到期的任务最多立即补跑一次，不逐条重放停机期间的历史触发。
- `skip-on-overlap`：同一 heartbeat agent 尚在运行时，后续触发记为 `skipped`，不会并发重入。
- 固定节拍：长任务完成后，下一次触发取原计划节拍上的首个未来时间点，不按“完成时间 + 间隔”重新计时。
- `at` 是一次性任务；执行后不再安排下一次。
- 手动运行不会改写尚未到期的自动触发时间。

因此，停机两小时或单次任务运行过久都不会形成补跑风暴，也不会让周期任务持续漂移。
