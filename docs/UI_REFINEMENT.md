## 已落实的生产路径

### 字号、密度

- 138 处宿主 JSX 固定像素字号作等值迁移，五档 `--type-*` 改为 rem，宿主 CSS 固定像素字号同步迁移。根字号只缩放一次，未再次乘 `--font-size-scale`；该变量保留为兼容/诊断值，不驱动第二次缩放。
- 三档密度有实际变量消费者：设置行、共用 ActionButton 和侧栏会话行。密度不改字号；触屏控件保留较大目标。其他历史控件仍随原语迁移批次接入，不冒称全站密度已彻底统一。
- 既有 9–11px 声明没有借换单位从债务计数里消失。`codeDebt.test.js` 继续识别其等值 rem；未将全部微型字一刀切抬升，也未宣称可读性债务清零。

### 滚动与边缘

- `scrollPinning.js` 区分用户滚动意图、吸底和跳转按钮显示。向上滚动立即释放吸底，冷却到期并不自动夺回阅读位置；点击回到最新显式恢复。
- 保留分页锚点、消息路由定位、活跃回合定位与 owner/session 挂载边界。
- `ScrollFadeContainer` 复用当前唯一滚动容器，监听容器和内容尺寸。触顶/底取消对应渐隐；短内容不建立无用 mask，避免额外文字合成差异。
- 本批接入纵向聊天阅读，不声称实现了通用双轴/RTL 遮罩库。浮动跳转按钮位于遮罩外，键盘聚焦时取消遮罩，原生纵向滚动条保留不透明区域。
- 用户关闭动画或系统减少动态效果时，显式滚动也改用 auto 而非 smooth。

### 弹层与动效

- 先验证模型弹层，再将上下文、权限模式和 Slash 菜单接入共享 `PopoverPortal`。菜单不再被 chat-main 的 containment 困住；保留 React context，处理局部 CSS 变量继承、窗口/滚动/visualViewport 变化与模态出现时关闭。
- 同步修正外部点击和 blur 的 DOM 包含判断；不能因 portal 内部点击而关闭菜单。Escape 保留 IME 守卫和原有焦点归还。
- 7 个 Framer Motion 使用点接入宿主动效适配器，关闭后 stop 并设置终态，而不只是缩短 CSS 动画。
- 系统减少动态效果使用实时媒体查询订阅；浏览器验证发现仅用库的初始 reduced-motion 快照不足以响应运行中切换，已补失败用例和修复。

### 原语与空态

- Settings、AddProviderPanel、ProviderSourcePicker、两处预览模式切换接入同一 Segmented。保留文件标签页的滚动/关闭行为，不把文件标签误改成设置胶囊。
- 分段控件采用纯几何独立指示器，不共享全局 layoutId。支持受控值、禁用项和方向键/Home/End；group/pressed 和 tablist 语义分别处理。
- 25 个加载图标消费者接入统一 Spinner，公开进行中状态采用节奏点，路由加载使用真实 Skeleton。刷新动作的 RefreshCw 保留其动作语义，不把全部刷新按钮变成加载指示器。
- 工具调用缺失时呈现 unavailable 空态，不崩溃、不编造 running。审批执行/成功权威未作视觉猜测。
- 补低优先级原生 disabled 回退；既有全局 focus-visible/active 规则保留。品牌识别色、主布局、Surface 四阶与角色圆角均未改。

## 阶段二：本地参考与工具审批回执

本地 `D:/open-claude-ui` 是干净的 `2834bc1`，与阶段一固定引用相同。读取其 McpToolDecisionCard、CdsButton 和文档 3.5 后继续适配：它们是逆向说明/示例，不等于独立验证过的 Claude 原厂完整源码。

- 示例通过 1200ms 定时器将“允许”变为 success，且将拒绝合并为 error；这些机制没有引入 Gugo。示例的无条件 always-allow 和拒绝后自动继续推理也不成为 Gugo 的权限策略。
- 新增独立审批回执展示，要求 host 的审批 ID、终态与请求/会话等对应；错误或缺字段、错误 ID、其他会话/回合、未知状态均不显示为已确认。
- 生产 useChatApprovals → ChatSplitView 接入 pending/submitting/resolved/error/unknown。批准只显示审批决定；实际工具执行仍由已有结果时间线证明。HTTP 200 的旧式 ok=true 而缺回执保持兼容等待流程，但展示为 unknown。
- 后端/用户/会话切换立即隐藏旧卡和旧回执；迟到 POST 不向新归属展示结果。正常回合 cleanup 不擦除已确认提示，新任务通过原有 accepted-send 边界清理提示，旧后端回调不能清理新归属。
- 危险、过期和未知状态不添加再次提交按钮；收起只清展示，不发送 approve/deny。未更改 POST 参数、数据库 schema、记住授权范围、取消/恢复或审批 gate。
- 审批操作接入共用 ActionButton，保留原先中性主按钮及描边按钮颜色与圆角；忙碌时反馈输入/Enter/submit 不得重复决定，IME Escape 不关闭候选中的输入。
- 真实浏览器发现 compact 的固定 padding 曾顶高 min-height，现由密度间距变量统一管理。sm 三档实测 28/32/36px，md 三档 32/36/40px，comfortable 保留其 32/36px 尺寸。
- 隔离 Web 调用真实审批 HTTP/SQLite：approve、deny、expired 验证实际回执；人为丢弃已提交的网络响应时 UI 保持 unknown、SQLite 已为 approved，且没有第二次 POST。客户端 7 次提交各一次，其中 5 次真实隔离 HTTP/SQLite、2 次分别注入旧式 ok 回应和 403；迟到响应跨 scope 不显示。没有运行模型或审批中的工具，演示目标文件未创建。
- 6 组批准结果宽度/主题截图无横向溢出；另保存 submitting/denied/unknown/error/expired。详见阶段二证据目录。最终冻结后从头 **1172 文件 PASS / 退出 0 / 1388.883 秒**，146 个改动代码/测试/配置文件的 SHA-256 前后一致；定向 14 文件/122 项、离线 71 项及本批门禁通过。见 [阶段二验收记录](review-evidence/ui-refinement-phase-2/verification.json)。阶段一的 1170 PASS 未冒充阶段二验收。

### Changes

- 删除内部“改动／文件”模式，不只是移到另一个地方。≡ 直接展开搜索和当前比较集的变更文件。
- 选择文件直接查看 Diff，不再自动切成完整文件阅读。完整文件浏览/预览仍在原有文件工作区，不新增入口。
- 比较目标移到 ⋯，保留会话/工作区/HEAD/分支比较能力。分屏、换行、空白显示、审查和反馈仍使用已有逻辑；审查入口使用当前比较集路径，不把 session 比较误替换成无关 Git 文件列表。
- 文件行携带原始路径而非 basename 再拼目录，显示必要父目录、当前选中项和增删统计；同名文件不会因目录不同而指向同一个文件，搜索也包含父路径。
- “本次改动”首次打开时将请求的 session 目标带入新挂载的面板，修复事件先于面板挂载而丢失目标的问题。session 比较直接读取会话变更 feed，不先扫描整个工作区 Git 状态。
- 补订阅清理，不保留卸载后的旧面板监听。无可显示文本差异时明确说明，而非反复提示重新选文件。

### 历史入口

- 左下角菜单不再显示历史，也不留下空白占位。正常最近会话/项目列表、侧栏比例及其他入口不变。
- 设置新增 history 区域，复用原有 HistoryView 的数据、搜索、打开、归档和重试处理；嵌入时不再包一套 AppLayout/侧栏/全屏 main。
- 保留 `/history` 老链接兼容，不删会话、归档或任务记录。新增内置设置 ID 也加入防插件覆盖的保留集合。

### 键盘与证据边界

真实窄屏复验发现外层焦点陷阱会在捕获阶段抢走 Escape，先于内层菜单/IME 关掉面板。修复仅调整事件：Tab 仍在捕获阶段做焦点约束，Escape 在冒泡阶段尊重内部处理和 composition；未处理的 Escape 仍可关闭外层。内部 ⋯ 的 Escape 关闭菜单并归还焦点，不误关整个 Changes。

新 Changes 测试的首个夹具缺少 t 参数，未把那轮报错当功能复现；修正夹具后在归档 `71b01e4` 源码副本复现三项失败，当前实现通过。真实历史入口/设置嵌入测试也先失败再修复。

浏览器检查 1440/360 × 三主题的 Changes 列表与设置历史，共 12 组；另保存左下角菜单、文件选中 Diff、高级选项。Changes 使用明确的合成会话 feed/Git 回应，没有执行模型或读写真实文件；历史使用本次创建的隔离 SQLite，会话搜索、归档筛选、打开原会话及老链接均实测，readonly 核验 3 个合成记录仍在，含 1 个归档。未改真实配置或用户数据。
