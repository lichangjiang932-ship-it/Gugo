# 跨项目工程记忆

- 配置保存、运行时目录与实际请求必须共享读取路径和身份绑定；“列表显示了”不能代替正确端点/协议的验证。
- 测试应隔离真实 home/config，而不是在生产代码设置隐蔽 opt-in 门槛来避免测试读取用户文件。
- 批量取消选用应保留候选及元数据，明确区别删除；部分表单保存不能回写过时的独立子面板快照。

- Windows Node ESM 使用 file URL；先通过 require.resolve 定位包入口，再用 pathToFileURL，不猜 lib/index.js。外部临时脚本避免多层 shell/模板字符串转义，选择清晰的独立脚本。
- 浏览器验收等待真实 DOM/数据/偏好状态就绪，不靠固定短 sleep。HMR 与原始模块 URL 缓存可能混入旧实现，最终复验使用新文档和隔离 profile。
- 浏览器临时 React 夹具必须复用页面实际加载的 React/ReactDOM 优化 URL（包含版本 hash）；不要混用无版本 URL 的第二份 React，把 dispatcher 为 null 误当业务 Hook 故障。
- 优化交互不等于授权重设计页面；用户要求保留原布局时，先锁定入口、名称、位置与组件边界，只改内部行为。
- 焦点陷阱的 Escape 应在内部控件处理之后尊重 defaultPrevented 和 IME；Tab 的焦点约束可独立留在捕获阶段，不要用一个 capture 监听抢走所有键。
- Portal 的 React 上下文与原生 DOM 归属是两件事；校验 contains、焦点、CSS 变量、模态层级和实际指针命中。
- 减少动态效果必须包含当前用户偏好、实时 OS 偏好以及正在运行的 JS 动画；仅缩短 CSS 或只读取挂载时的媒体快照不充分。
- 所谓执行成功、检查通过、目标满足必须分别有证据；审批/删除/重命名未知结果不重放、不提前宣布成功。
- 参考逆向或设计仓库固定提交与许可证，区分仓库自述、静态可见事实和独立运行证据，不把相似路径当作全部结论的验证。
